# Work type 01 — comparison / "X alternative"

**Category:** `product/` · **Frontmatter `category`:** `Comparison`
**Length:** 2,500–3,800 words · **Links:** 18+ (8+ internal)

## Required sections, in order

1. `## Why teams search for a {{Competitor}} alternative` — the three walls, numbered, each
   traceable to that vendor's public pricing or docs.
2. `## Side-by-side feature gating` — a capability table, {{Competitor}} + two adjacent
   vendors + **nRouter**. Every competitor cell traces to a source linked in `## Sources`.
   Follow the table with the trademark disclaimer paragraph.
3. `## Pricing tiers explained` — the nRouter plan table, then the breakeven arithmetic
   worked out loud with the actual numbers from `/pricing`.
4. `## What {{Competitor}} does better` — non-negotiable. Name at least two things
   honestly. A comparison with no losses is an advertisement and readers discount it.
5. `## Switch cost: one base URL, one API key` — a `diff` code block showing the two-line
   change to `https://api.nrouter.ai/v1` + `NROUTER_API_KEY`.
6. `## Migrating your {{Competitor}}-specific config` — what maps, what does not, what has
   no equivalent.
7. `## Why "every feature on every plan" is sustainable` — the capacity-reservation answer.
8. `## When nRouter is the right choice` — a two-or-more-of-the-following list.
9. `## When to stay on {{Competitor}}` — a real list, not a straw man.
10. `## Try it` → `## See also` → `## Sources`.

## Proof obligation

- Every competitor number is dated and linked. Verified date in `## Sources`.
- The trademark disclaimer appears once, right after the comparison table.
- Link the `/vs/{{competitor}}` landing page where one exists; it is this post's
  high-intent sibling and the two must not contradict each other.
- Link at least three other `*-alternative` posts as `See also` — the comparison cluster is
  how a buyer navigates, and an orphan comparison post ranks for nothing.
