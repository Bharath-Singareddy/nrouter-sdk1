# Work type 05 — product capability

**Category:** `product/` · **Frontmatter `category`:** `Product`
**Length:** 1,800–2,800 words · **Links:** 14+ (7+ internal)

## Required sections, in order

1. `## What it does` — blockquote answer, then the one-paragraph version.
2. `## The job it does for you` — the workflow before, the workflow after.
3. `## How it works` — customer-visible contract: what you configure, what the gateway
   does, what you get back.
4. `## Set it up` — a real procedure, code block or exact dashboard path.
5. `## Worked example with numbers` — an actual scenario costed out in a table.
6. `## What it costs` — the plan/fee reality from `/pricing`, stated plainly.
7. `## Where it fits with the rest of the platform` — the adjacent capabilities and their
   posts, linked.
8. `## Limits and what it will not do` — required. An unqualified capability post reads as
   marketing and is discounted accordingly.
9. `## Try it` → `## See also` → `## Sources`.

## Proof obligation

- Every capability described is one a customer can use today. No roadmap in the present
  tense; a future item is labelled as one.
- Prices and fees come from `/pricing`; model names from `/models`.
- Link `https://app.nrouter.ai/signup` once, in `## Try it`, with the actual starting amount — never a vague
  "get started free".
