# nRouter Cinematic Brand Identity

## Environment & Lighting
- **Setting:** Dim, modern operations rooms or minimalist dark-mode tech studio environments.
- **Lighting Physics:** Volumetric light spilling from monitors, soft cyan and amber rim lighting on brushed aluminum or matte-black surfaces.
- **Color Grade:** Cool teal-and-orange cinematic LUT (6500K key light), deep blacks.

## Interface Elements
- **Dashboard UI:** Sleek dark-mode network analytics, glowing data visualizations, animated real-time traffic graphs, pulsing node topology maps.
